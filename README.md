# 手語心島

以〈第六章 臺灣手語的教與學〉為內容的六角格積木風互動學習島。

**線上瀏覽：** https://chuang1985.github.io/tsl-heart-island/

## 玩法

- 九座六角島對應本章九節，外圈八座照第一到第八節排列，中央心島是第九節「結語」。
- 點地面走路、點島民對話，答對選擇題或詞卡排序題可以得到積木，島上的「待建造」工地會跟著蓋起來。
- 故事任務〈雞蛋與瓦片〉共四段，四個小遊戲：句型拉霸機、連連看、對話練習、語句拆合。
- 37 位島民的題目都依本章內容設計並標註頁碼；每個錯誤選項都有針對性的回饋，排序題會提示有幾張位置正確。
- 學習日誌會收錄答對的重點，並以雷達圖顯示本章五個向度的進度：語言功能（第1–2、9節）、詞彙教學（第3節）、句型與對話（第4節）、課文與活動（第5–6節）、文化與評量（第7–8節）。
- 空間表達的說明另參考張榮興（2008）〈華語與臺灣手語動態空間結構之對比分析〉，《華語文教學研究》5(1)，87–112。

進度只存在各人自己的瀏覽器裡，不會上傳。

## 檔案

- `heart-tsl-island.html`：整個遊戲（單一 HTML 檔，three.js 從 CDN 載入）
- `index.html`：導向遊戲頁

## 本機執行

直接用瀏覽器開啟 `heart-tsl-island.html` 即可；或在資料夾內執行：

```bash
python -m http.server 8765
```

再打開 http://localhost:8765/
